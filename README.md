# Technical Content Portfolio

A hands-on portfolio exploring developer documentation,
documentation engineering, AI-assisted content operations,
and developer education.

## What I'm exploring

This portfolio demonstrates how technical content can be
designed, maintained, tested, automated, and improved using
modern open-source tools.

### 01. Developer Documentation
Building and maintaining product documentation using
docs-as-code workflows, structured content, API references,
and documentation quality checks.

### 02. Documentation Operations and AI
Experimenting with documentation analysis, change detection,
retrieval-augmented generation (RAG), and AI-assisted
documentation workflows.

### 03. Developer Education
Creating practical tutorials, working examples, API
walkthroughs, and learning materials for developers.

### 04. Documentation Standards
Developing style guidelines, reusable templates, content
standards, and automated quality checks.
